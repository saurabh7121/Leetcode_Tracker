# 🚀 LeetCode Progress Tracker

A full-stack web application built with Vite, React, and Node.js/Express to track and analyze your LeetCode problem-solving journey. It features a scalable, modular architecture with decoupled routes and secure JWT authentication middleware.

---

## 🛠️ Tech Stack

* **Frontend:** React 19, Vite, Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB (via Mongoose ODM)
* **Authentication:** JSON Web Tokens (JWT) & Custom Auth Middleware
